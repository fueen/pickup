# v1.3.4 App Info, Changelog, and Splash Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the v1.3.4 supplement: one-time changelog modal, PickUp about page, and livelier splash animation.

**Architecture:** App metadata and changelog entries live in constants. AsyncStorage acknowledgment logic lives in a small service with unit tests. UI components consume those constants and service from `_layout.tsx`, `settings.tsx`, `about.tsx`, and `SplashScreen.tsx`.

**Tech Stack:** Expo SDK 54, React Native 0.81.5, expo-router 6, AsyncStorage, Jest/ts-jest.
