方向说明

这是最稳的一版：它不会推翻现有 LOGO，只是重绘比例和动效。动效先出现两张背卡，再由前景圆角框锁定品牌符号，最后标题轻落。

推荐落地高识别低风险
  • 图标可直接重绘成 PNG / SVG，再生成 adaptive icon。
  • 开屏动画适合用 React Native Animated 实现，主要是 translate / rotate / scale / opacity。
  • 字体建议继续用粗圆系统字，标题可略收紧但不做负字距。
